# Security Policy

This is a small hobby project. I do my best to write secure code, but I can't guarantee prompt fixes.

## Reporting a Vulnerability

If you find a security issue, **open a GitHub Issue** with the `security` label. Don't send emails — issues are easier for me to track.

Please include:

- A description of the issue
- Steps to reproduce (if applicable)
- Potential impact

## What to Expect

- I'll acknowledge the issue when I see it.
- Fixes come when they come. This isn't my full-time job, so please be patient.
- If the issue is serious, I'll do my best to prioritize it.

Thanks for looking out.
