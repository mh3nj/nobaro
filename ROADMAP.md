# Roadmap

> **Disclaimer:** This is a solo project. All timelines are aspirational, not promises. Life happens, motivation ebbs and flows. If something slips, it's because I'm one person.

## Short-term (next few months)

- [ ] Finish the Flutter mobile app — feature parity with the desktop version
- [ ] Note sync between desktop and mobile (local network or cloud)
- [ ] Polish the desktop editor — undo/redo, better image handling, smoother UX
- [ ] Keyboard shortcuts overhaul
- [ ] Proper error handling and crash reporting

## Mid-term (this year, maybe)

- [ ] Optional cloud sync (end-to-end encrypted, BYO storage or built-in)
- [ ] Plugin system — let people write small extensions without forking the whole app
- [ ] Theme store or theme editor
- [ ] Linux packages (.deb, .rpm, Flatpak)
- [ ] Windows installer (NSIS or similar)
- [ ] Mobile push notifications for streak reminders / daily quotes

## Long-term (who knows)

- [ ] Collaborative notes — real-time or async sharing between users
- [ ] Web version (possibly Lite) for browser access
- [ ] Public API for third-party integrations
- [ ] Native mobile notifications and widgets
- [ ] Translation system / i18n

## Non-goals (for now)

- Replacing Obsidian, Notion, or any other big notes app. Nobaro is a *digital soul*, not a productivity tool.
- Monetization. No subscriptions. No ads. No AI slop.
